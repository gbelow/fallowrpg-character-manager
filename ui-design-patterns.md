
1. this is a character sheet simulator. I think it is better designed as an experts tool. flexibility, 
  organization and clarity are the main goal.  
  
2. I prefer to have many things on the screen at once. Elements affect each other and I think it is
  important to know when it happens. Also, many game operations occur manually by the player, so it s
  important to have all the info on the screen simultaneously.
  
  
3. I need the sidebar or another secondary bar to have the catalogue of assets, like items, abilities,
  characters, etc. Some things will have to be collapsed to be able to fit everything on the screen. The skills section and resources are the most important to have always visible. Tabs are essential, since each has a different function. I am open to suggestions


4. aesthetics should be clean.

5. important interactions:
creation mode: creating a character from a pool of XP and karma(used to buy talents)
click to roll: this spends resource and displays result. usable in many forseeable situations.
focus modes: the play section can include fighting or exploration. Different info sets are relevant.
information: skills can be used in different ways. I want some way to display the options. Informations are still in the external rulebook 
state change indication: it should be clear how the values are calculated.
